# Beginner Python Projects

This folder contains a few simple Python projects for beginners. Each project uses only the Python standard library and can be run from the terminal.

## Projects

1. `todo_cli.py` - A small to-do list manager
2. `guessing_game.py` - A number guessing game
3. `calculator.py` - A simple arithmetic calculator
4. `password_generator.py` - A random password generator

## Run a project

```bash
python beginner_projects/todo_cli.py
python beginner_projects/guessing_game.py
python beginner_projects/calculator.py
python beginner_projects/password_generator.py
```

## Skills practiced

- Variables and functions
- User input
- Lists and dictionaries
- Loops and conditionals
- Basic CLI design
